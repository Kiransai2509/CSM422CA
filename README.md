# Financial Time-Series Forecasting Dashboard

An academic portfolio dashboard that presents experiments comparing recurrent neural networks and simple baselines for financial return forecasting.

## Included pages
- Overview of the recorded cross-market test metrics
- Experiment 2: lookback sensitivity and walk-forward model comparison
- Experiment 3: feature-set ablation on development validation data
- Experiment 4: NIFTY Bank cross-market evaluation and yearly metrics
- Methodology and limitations

## Run locally

1. Install Python 3.10+.
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `streamlit run app.py`

The `data/` folder must contain the CSV output files generated by the experiment notebooks. This dashboard packaging notebook copies those files into the folder.

## Deploy to Streamlit Community Cloud

1. Upload the complete project folder to a GitHub repository.
2. In Streamlit Community Cloud, create an app from that repository.
3. Set the main file path to `app.py`.
4. Ensure `requirements.txt` and the `data/` directory are committed.

## Research caution

The recorded GRU model did not consistently outperform simple return-forecasting baselines on the external-market test. The app reports that result rather than claiming a predictive edge. Forecasting error metrics do not establish a profitable trading strategy. This is an educational project and not investment advice.
